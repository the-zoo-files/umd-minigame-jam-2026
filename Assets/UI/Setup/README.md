# Setup design assets

Source: [Figma setup screen, node 65:142](https://www.figma.com/design/vgrxToBrx8UrROuNanwNpD/UMD-Minigame-Jam?node-id=65-142).

- `Background.png` is the exported decorative background node 65:143, not a screenshot of the screen.
- `imgImage5.png` is the exact practice-preview image fill.
- `imgGroup*.svg` and selector SVGs are the supplied control assets, using their hex color fallbacks for Unity SVG importer compatibility; their PNG siblings preserve their artwork for Unity's texture importer.
- `ControlSlash.png` and `StartSlash.png` are Figma's rendered separator nodes 65:228 and 65:250, including their rotation.
- Thumbnails reuse `Assets/UI/Lobby/TestudoPortrait.png`, which is byte-identical to the supplied Figma character image.
- Soft, pill, and thumbnail shadows are reusable sliced textures generated by `GameSetupAssetSetup` from the design's corner/blur settings.

The setup body font is Fredoka Medium (weight 500, width 100), instantiated from the [official Google Fonts Fredoka source](https://github.com/google/fonts/tree/main/ofl/fredoka). Its license is preserved in `Assets/Fonts/Fredoka-Setup-OFL.txt`. Fredoka One headers reuse the lobby font asset.

Run `tools/prepare-setup-assets.cjs` with `sharp` available to regenerate the PNG versions. Set `SETUP_SHARP_MODULE` to an absolute module path when using a bundled runtime. Then use **Tools > UmdJam > Configure Game Setup Assets** to preserve native texture dimensions, configure imports, and generate shadows/font assets through Unity APIs.
